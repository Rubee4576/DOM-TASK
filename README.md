# JavaScript DOM and Event Handling

## Description

This project is a simple web page created using HTML, CSS and JavaScript.

## Features

- Displays "Hello" initially.
- Takes the user's name as input.
- Changes the greeting when the Greet button is clicked.
- Contains four boxes: Red, Blue, Green and Yellow.
- Changes the background colour of each box when it is clicked.

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM
- Event Handling

## How to Run

Open the index.html file in a web browser.
